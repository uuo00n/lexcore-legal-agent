# ChatGPT 测试数据集生成 Prompt

将以下内容复制到 ChatGPT，生成 100 条法律场景测试案例。

---

## Prompt

```
你是一个中国法律测试数据生成专家。我需要你生成 100 条法律问答测试案例，用于评测一个法律 AI 助手的检索和回答质量。

## 输出格式

输出一个 JSON 数组，每条数据格式如下：

```json
[
  {
    "question": "用户的口语化法律问题",
    "ground_truth": "标准答案（2-4句话，包含关键法律要点）",
    "ground_truth_contexts": ["法律名_第X条", "法律名_第Y条"],
    "acceptable_contexts": ["法律名_第X条", "法律名_第Y条"],
    "corpus_status": "in_corpus"
  }
]
```

## 要求

### question 字段
- 模拟真实用户的口语化提问方式
- 包含具体场景描述（不是抽象的法律概念提问）
- 难度分布：简单 40 条、中等 40 条、复杂 20 条
  - 简单：单一法律问题，答案在 1-2 条法条中
  - 中等：需要结合 2-3 条法条综合回答
  - 复杂：涉及多部法律交叉、或需要区分不同情形

### ground_truth 字段
- 标准答案必须包含具体的法律分析（3-5 句话）
- 不能是泛泛而谈的建议（如"建议咨询律师"、"可以向有关部门举报"）
- 必须说明：具体的法律后果、权利义务关系、适用条件
- 必须引用具体法条编号（如"依据《劳动合同法》第四十六条"）
- 如果涉及多种情形，要区分说明

**反面示例（太简单，不合格）：**
```
"ground_truth": "应及时向学校、教育行政部门及公安机关举报，保护未成年人权益。"
```

**正面示例（有法律分析深度）：**
```
"ground_truth": "学校对校园欺凌负有防控和处理义务，发现欺凌行为应当立即制止并通知家长，未履行职责的学校应承担责任。家长可以向教育行政部门投诉，情节严重的可向公安机关报案。造成人身损害的，可依据民法典要求侵权人及学校承担赔偿责任。"
```

### ground_truth_contexts 字段
- 格式严格为：`{法律名}_{第X条}`
- 法律名不带书名号，不带"中华人民共和国"前缀
- 示例：`民法典_第一千零六十三条`、`劳动合同法_第四十六条`、`刑法_第二百六十四条`
- 只列出最直接相关的法条（1-4 条）
- 必须是具体的实体条款，不能只引用原则性条款（如"第一条"、"第二条"、"第三条"这种总则开头的条款通常不够具体）

### acceptable_contexts 字段
- 如果只有一个标准答案，填入与 `ground_truth_contexts` 相同的列表
- 如果存在合理替代法条，也一并列入。例如“加班不给加班费”可以接受 `劳动法_第四十四条`，也可以接受 `劳动合同法_第三十一条`、`劳动合同法_第八十五条`
- 不要把只是宽泛相关、不能直接回答问题的法条放入该字段

### corpus_status 字段
- 本地法库存在所有标准法条时，填 `"in_corpus"`
- 如果题目故意测试本地法库外内容，填 `"out_of_corpus"`；这类题不会计入本地 RAG 检索汇总指标

### 场景类型分布

- 劳动纠纷：15 条（加班工资、辞退补偿、试用期、竞业限制等）

## 注意事项

- 法条编号必须真实存在，并且必须能在本地 `data/laws/` 切分结果中找到；不要编造超出范围或本地法库不存在的条号
- 问题要贴近生活，像真实用户会问的那样
- 不要出现"请问"、"您好"等客套话，直接描述场景或提问
```

## 使用说明

1. 将上面的 prompt 复制到 ChatGPT（推荐 GPT-4）
2. 获取输出的 JSON 数组
3. 用本地 chunk 列表校验 `ground_truth_contexts` 和 `acceptable_contexts`
4. 保存为 `eval/dataset.json`
5. 建议人工抽查 10-20 条，验证问题、答案和法条语义是否一致

## chunk_id 格式参考

系统中的 chunk_id 格式为 `{法律名}_{第X条}`，例如：
- `民法典_第七百一十四条`
- `劳动合同法_第四十六条`
- `刑法_第二百六十四条`
- `消费者权益保护法_第二十五条`
- `公司法_第一百七十一条`

`ground_truth_contexts` 中的值必须与此格式完全一致。
